# G-27 露天式圆形水池结构设计程序（Python / Tkinter 版）

对老牌 DOS/VB 水利程序集 **G-27《露天式圆形水池结构设计程序》** 的界面重新设计与实现，
计算方法参照张光斗《圆筒钢筋砼薄壁池的内力计算》(水利电力出版社)。

## 运行

```bash
pip install -r requirements.txt
python gui.py
```

## 目录

- `engine.py` — 计算引擎（池壁内水压力/温差内力、池底自重/温差内力、附加内力等）
- `gui.py` — Tkinter 图形界面，五个选项卡：数据来源 / 文本结果 / 图形结果 / 程序说明 / 使用帮助
- `G-27-1.INT` — 原程序算例数据，启动自动加载，用于核对计算结果

## 各分项计算可信度

| 分项 | 可信度 | 说明 |
|---|---|---|
| 池壁·内水压力内力 | 精确 | 公式已从原说明书公式图片逐字核对，算例复算零误差 |
| 池底·自重内力 | 精确 | 标准固支圆板理论，零误差 |
| 池底·温差弯矩 | 精确 | 标准平板温差公式，零误差 |
| 池壁·温差内力 | 中等 | 公式结构确认，比例常数按算例反标定，误差 <1% |
| 池壁池底联合附加内力 | 近似 | 未反推出通用闭式公式，按算例经验标定，仅供参考 |

详见程序内「程序说明」页。

## 下载可执行文件 (Windows .exe)

本仓库通过 GitHub Actions 自动用 PyInstaller 打包 Windows 版可执行文件：

- 每次推送到 `main` 分支：在 Actions 页面对应 workflow run 的 **Artifacts** 中下载 `G27WaterTank-windows-exe`
- 打 `v*` 标签发布正式版（如 `git tag v1.0 && git push origin v1.0`）：在 **Releases** 页面下载 `G27WaterTank.exe`
